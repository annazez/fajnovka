# Security policy

## Supported versions

Only the newest version on the `main` branch gets fixes. The site <https://fajnovka.zezulka.me> always runs that version.

## Report a vulnerability

Do not open a public issue for a security problem.

1. Open the **Security** tab of this repository.
2. Select **Report a vulnerability**. Only the maintainers see the report.

If you cannot use GitHub, send an e-mail to <anna.zezulka@proton.me>.

Give this information in the report:

- the address or the file that has the problem,
- the steps that show the problem,
- the effect that an attacker can get.

## What you can expect

The maintainers are volunteers. They try to answer in 7 days. They tell you when the fix is on the site. If you want it, the commit of the fix gives your name.

## Scope

In the scope:

- the code in this repository,
- the site <https://fajnovka.zezulka.me>, with its server function `/api/occupancy`.

Not in the scope:

- the platforms of other parties (Vercel, GitHub, the dashboard of DPO),
- a result of an automatic scanner without a proof of an effect.

The site keeps no personal data, sets no cookies and has no user accounts.
